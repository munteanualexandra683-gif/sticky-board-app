# Stickee

Stickee is a digital sticky-note board built on an infinite canvas. I am building this as a **passion project** to push my skills and learn modern React, Framer Motion physics, and advanced UI/UX design patterns. My goal is to create an experience that feels incredibly fluid and tactile.

> 🚧 **Work in Progress:** This app is currently under active construction! I am building and pushing new features constantly as I learn.

## Current Features
- **Infinite Canvas:** Pan and zoom freely across an endless workspace.
- **Sticky Notes:** Create, edit, and color-code digital sticky notes.
- **Tactile Physics:** Drag and drop elements with smooth, physics-based interactions.

## What's Next?
- **Scrapbook Elements:** The ability to add photos, pins, or stickers.
- **Multiplayer:** Real-time collaboration so multiple people can use the board at once.
- **Custom Themes:** Support for different board backgrounds and visual themes.
- **Desktop Version:** Wrapping the app to run natively on Mac and Windows.

## Built with
- React + TypeScript + Vite
- Framer Motion & @use-gesture (for physics and animations)
- Vanilla CSS
- Lucide React (for icons)
